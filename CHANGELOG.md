# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-28

### Added
- Complete MVP release of the StoryTree collaborative storytelling platform.
- Modular monolith architecture with Turborepo and Next.js.
- Centralized database package using Prisma and PostgreSQL.
- Comprehensive UI component library (`@repo/ui`).
- Shared configurations (`@repo/eslint-config`, `@repo/typescript-config`).
- User authentication and session management using Better Auth.
- Robust seeding system with realistic English content for development and demonstration.
- Responsive, accessible design system implementation.
- Core features including Feed, Discovery, Recommendations, Profiles, Notifications, Comments, Likes, and Bookmarks.
