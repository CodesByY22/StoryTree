# Security Policy

## Supported Versions

Currently, only the latest major release (1.x.x) is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within StoryTree, please DO NOT disclose it publicly.

Instead, please send an email to the repository maintainers or open a private GitHub security advisory. 
We take all security vulnerabilities seriously and will work to resolve them quickly.

We will try to acknowledge your report within 48 hours, and will provide an estimated timeline for the fix. Once the fix is verified and deployed, a public disclosure will be made acknowledging your contribution (if desired).
